# ⚡ ImmerseTL (Immersive YouTube Translate)

ImmerseTL is a premium, open-source Chrome Extension designed to fix YouTube's jumpy auto-translate subtitles and provide a highly aesthetic, glassmorphism-styled subtitle overlay. Perfect for watching VTubers, Anime, or any foreign livestreams!

## ✨ Features
* **Smart Text Buffering:** No more blinking or vanishing subtitles. Text is held on screen longer and stitched together intelligently.
* **Dual Subtitle Mode (Romaji + Translation):** Built-in active translator that pulls Japanese text and converts it into Romaji (ABC) and your preferred language simultaneously!
* **Glassmorphism UI:** Stunning, customizable Apple-like blur effects and semi-transparent backgrounds.
* **Auto-Translate Forcer:** Automatically forces YouTube to turn on Auto-Translate for you.
* **Smart Highlighter:** Automatically highlights expressions like `[Laughs]`, `haha`, `lol`, and emotes (⭐, ♪, ♥) in beautiful pastel colors.
* **Draggable Subtitles:** Move the subtitle box anywhere on your screen.
* **Chat History Log:** Keeps a transcript of the subtitles in a draggable, minimizable side-window.

## 🚀 How to Install (Free / No Web Store Needed)
Since this extension is not published on the Chrome Web Store, you can easily install it manually:

1. Click the green **"Code"** button at the top of this repository and select **"Download ZIP"**.
2. Extract the downloaded ZIP file to a folder on your computer (e.g., `Documents/ImmerseTL`).
3. Open Google Chrome and go to `chrome://extensions/`.
4. Turn on **"Developer mode"** (toggle switch in the top right corner).
5. Click the **"Load unpacked"** button in the top left.
6. Select the folder where you extracted the ZIP file.
7. Done! The extension is now installed. Pin it to your toolbar to access the settings!

## ⚙️ Settings & Usage
Click on the ImmerseTL icon in your Chrome extension bar to open the Control Panel.
* **Mode Operasi (Operation Mode):** Choose between regular buffering or Dual Subtitle (Romaji + English/Indonesian).
* **Blur & Opacity Sliders:** Adjust the aesthetic of your subtitle background.
* **Font Color:** Choose from various anime-styled colors.
* **Drag & Drop:** Click and drag the subtitle box on YouTube to move it out of the way.

## 📝 Disclaimer
This extension relies on YouTube's current DOM structure and Google Translate's unofficial API. If YouTube changes their layout, some features may need an update.
